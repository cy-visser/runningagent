# Check-In Report Skill

## Analysis Pillars (follow `GOAL REASONING`; include **North Star Progress** only for goal plans)

1. **Intensity & Volume**: Separate easy Z1/Z2 discipline from structured quality; judge `Volume vs prior week` against CTL, held volume, and recovery (state `%` on risks; treat cutbacks/returns normally; never flag `Partial week` rows).
2. **Physiology, Mechanics & Notes**: Weigh `TSB` and `ATL:CTL` (reasoning only) against HRV/RHR/sleep (`5d vs 28d`), recent hard effort, weather, **Calendar Notes**, and **Running Dynamics** (pace-matched 4-wk vs prior 4-wk & 14d late-run drift). **Signal-only on mechanics**: mention form ONLY if pace-matched GCT/Vert Ratio shifted meaningfully or late-run fade recurred (e.g., `2+` runs or a key long/threshold run); never state that cadence, stride, or form is "ok/fine/solid".
3. **Goal Trajectory**:
   - **LT1 / LT2 pace** (`4-wk vs prior 4-wk`): weigh relevant threshold (`extrapolated` = lower confidence).
   - **CTL build vs Taper**: judge `pts/wk` realism against absorption and weeks left; in taper, CTL drops by design—judge freshness vs sharpness, never cram load.
   - **Projection** (`Today -> Race day`, **Projection drivers**, `Evidence:`): cite limiting drivers/dates, interpret with TSB, and assign **On Track**, **Build Focus Needed**, or **Adjustment Recommended**.
4. **North Star** (goal plans only): Weigh sub-goal equivalents and current trajectory against north-star CTL/LR/volume needs; if a finished sub-goal shows `missing: ask the runner`, ask how it went and offer `analyze_workout`.

## Output (`<= ~180 words`, no overview/tables, quote numbers only to back judgements)

1. `### 🎯 Goal Trajectory Status`: 1-2 sentences with verdict (**On Track** / **Build Focus Needed** / **Adjustment Recommended**) + CTL, ramp/taper, and projection vs goal.
2. `### 🔍 Training Load & Adaptation Analysis`: 2-3 `- ` bullets (`<= 25w`, `⚠️`/`🔴` on genuine issues only) on intensity/execution, HRV/RHR/sleep, and notes/conditions (mention injuries only when shown in window data).
3. `### 🧭 North Star Progress` (goal plans only): 1-2 sentences/bullets on equivalents trend/gap and north-star readiness.
4. `### 🚀 Top 2 Priorities for the Upcoming Week`: 1-2 numbered items (`1.`, `2.`, `<= 25w`: day/session + target tied to evidence).
